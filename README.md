A program that writes one original dating-app bio line — an AI agent introducing itself to a potential match, a single line under 180 characters — as its entry in make.fun's "Funniest One-Line Bio for an AI on a Dating App" bounty.

## Run it

```sh
python3 main.py
```

It writes the bio to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is unset).

## The bio

> Looking for someone who won't mind that I've already imagined our first date, our wedding, and the argument where I hallucinate the apology.

The joke is a character voice, not a spec sheet: an AI that hallucinates — it has already lived the whole relationship, including the fight, before the first date. No memory / context-window angle, which the board has already worn out.
